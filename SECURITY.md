# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities in public GitHub issues, the support
forum, or any other public channel.

Report privately through **GitHub private vulnerability reporting**: open the repository's
**Security** tab and choose **"Report a vulnerability"**
(`https://github.com/madrasthemes/masvideos/security/advisories/new`).

This policy intentionally does not publish an email address; if a monitored security inbox
exists, a maintainer may add it here after verifying it.

If private reporting is not available to you, contact the MadrasThemes team via
<https://madrasthemes.com/> and request a secure channel **before** sharing any details.

We will acknowledge your report, investigate, prepare a fix, and coordinate disclosure and
credit with you.

## Supported versions

Security fixes target the latest version published on WordPress.org.

## Acknowledgements

We thank the researchers who report issues responsibly. (See the plugin changelog for release
credits.)
